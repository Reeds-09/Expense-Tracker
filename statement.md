Project Statement: Simple Python Monthly Expense Tracker



Problem Statement:

To make a expense tracking program using key concepts of python programming language which wis easy to use and reliable 



Scope of the Project:

The scope of this project is  basic personal expense tracking via a command-line interface. It covers:

Accepting user inputs for expense names and amounts.

Saving records to a local plain-text file (expenses.txt).

Reading and displaying stored records back to the user.

Simple menu-driven navigation using loops and conditional statements.



Target Users:

Students and Beginners: Individuals learning basic Python programming who need a simple project example.

Personal Users: In need of small , easy to use program to track daily expenses


High-Level Features:
Interactive command-line menu system.

Function-based modular design (add_expense, view_expenses, main).

Local file input and output (open, read, append, close).

Basic error handling for empty or missing files.
